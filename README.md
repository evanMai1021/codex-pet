# Codex Pet · 楪祈

Windows 桌面悬浮公仔，默认红白服楪祈，可切换红黑战斗服。通过 Codex 插件设置服装、显示、大小、趴边和任务气泡，修改立即生效并自动保存；也支持独立运行。

## 功能与预览

- **双服装与动画**：红白服、红黑战斗服各有16个透明视频动作，覆盖日常状态、互动、睡眠及四边趴边；视频不可用时回退图集。
- **退出宠物**：设置页和公仔右键菜单均可退出，停止桌宠窗口及其后台查询进程；退出后本次会话不再自动运行；开启随 Codex 启动时，下次启动 Codex 自动恢复，偏好保留。关闭“显示桌面公仔”仍是隐藏。
- **公仔控制**：拖动、单击互动、显示/隐藏、三档角色大小、允许趴边和减少动态。关闭趴边后仍可自由拖动。
- **分页与常驻气泡**：查看任务状态、剩余额度和今日 Token 用量，思考云朵外形，可选择空闲常驻页面、调整气泡大小、方向和位置微调；拖动时临时隐藏，按显示器可用区域定位。
- **额度显示**：选择是否展示公仔下方额度条，在双列卡片与纵向详情之间选择，并显示可取得的下次重置时间；未知值保留占位。
- **设置预览**：服装和额度布局均有预览，当前选择自动高亮。
- **更新与随启动**：插件面板提供更新检查、进度、下载校验和设置迁移。可选择随 Codex 插件加载启动，不添加开机启动项。

## 安装与使用

### 运行便携版

1. 打开[正式下载页](https://github.com/evanMai1021/codex-pet/releases/latest)，下载名称以 `inori-codex-pet-v` 开头的程序 ZIP。`codex-pet-source` 是源码包，不能直接当程序运行。
2. 解压到有写入权限的目录，双击 `楪祈桌宠.exe`；不要在 ZIP 压缩包内运行。
3. 配置插件后，可在 Codex 中调整设置。独立使用时，运行 `楪祈桌宠.exe --settings` 打开设置，通过公仔右键菜单退出。

### 安装 Codex 插件

需要 Windows、可用的 Node.js 和 Codex CLI。便携程序自带运行库，直接运行不需要另外安装 Python 或 npm 依赖。

在正式下载页下载名称以 `codex-pet-plugin-v` 开头的插件 ZIP，并解压。在包含 `.agents` 和 `plugins` 的插件目录打开 PowerShell：

```powershell
codex plugin marketplace add .
codex plugin add codex-pet@inori-pet-local
```

首次手动安装还需从源码包根目录执行以下命令，将插件指向便携程序：

```powershell
python scripts/configure_plugin.py '你的完整路径\楪祈桌宠.exe'
```

该配置命令需要 Python，仅用于这一步手动配置，并会备份原启动配置。然后重新加载插件，打开“楪祈桌宠设置”面板。程序已配置时，可点击“打开宠物”。完整步骤见[安装与源码启动](docs/INSTALL.md)。

### 更新已有安装

插件设置面板 → **版本与更新** → **检查更新** → **更新桌宠与插件**。

更新器校验下载、迁移设置并保留旧目录，完成后重新加载插件。下载需要网络，插件安装需要可用的 Codex CLI。

早期安装若没有更新入口，或不能识别同版本修订，需先按[手动迁移步骤](docs/UPDATE-0.1.14-REVISION.md)更新一次，并保留 `resources/run-data/settings.json`。使用过版本号较高的历史中间包时，也需先手动迁移。

Windows 若提示插件缓存被占用，先保存工作并关闭使用旧插件的 Codex，在外部终端更新插件后重新打开；不要手工覆盖缓存。

## 常用设置

在插件面板选择服装、角色大小、是否显示额度条、额度详情样式，以及任务气泡的语气、大小和自定义短句。在“任务气泡”中选择自动、左侧、右侧、上方或下方；水平微调负数向左、正数向右，垂直微调负数向上、正数向下。两项范围均为-400～400，点击“恢复默认气泡位置”可还原。点击气泡右上角“×”会同时关闭自动显示，并同步右键菜单与设置页；手动打开额度气泡不会重新开启自动显示。气泡计数仅统计明确工作中、等待操作的聊天，状态未知单独标为待确认，已结束聊天不计入进行中。任务、额度和用量共用位置，空间不足时自动避让。显示开关暂时隐藏公仔，完全退出可用插件设置页“退出宠物”或公仔右键菜单。

额度条靠近屏幕边缘时可临时挪动公仔避让；本次运行中往返切换额度条会恢复相应开关前位置。手动拖动、更换服装/大小/趴边或显示器变化后，以新位置为准，不跳回旧位置。

在插件设置的“任务气泡 → 气泡常驻内容”中，可选择任务状态、剩余额度或今日用量；默认不常驻。空闲时显示所选页，聊天进行时自动切换任务页，结束后返回所选页。常驻独立于“自动显示任务气泡”；点击气泡右上角×会同时关闭常驻与自动显示。公仔隐藏、拖动或退出时气泡仍会随之隐藏。

“减少动态效果”使用同一视频素材的静止画面，保持角色缩放；恢复动态后继续播放。某动作没有视频或视频无法解码时仍使用原图集回退。

气泡采用漫画思考云朵外形，圆点尾巴朝向公仔。任务正文使用13～15px的文字层级，气泡整体大小仍可在插件设置调整。会话累计用量默认折叠在任务页右下角的“会话用量”按钮中，点击展开，再点收起；定时更新不会自动展开或收起，退出程序后下次默认折叠。

“会话用量”按钮固定在翻页栏上方，展开后显示“收起用量”；正文滚动不会把收起按钮带走，点击收起会返回原阅读位置。额度和今日用量页面不显示这个按钮。

实时桌面接口不可用时，健康且新鲜的本地任务记录仍可显示工作中或等待回答，并注明本地状态；证据超过3分钟或发生冲突时保持待确认。此回退不表示实时审批通道已恢复。

随 Codex 启动默认关闭；开启后随插件加载启动，并跟随宿主退出。独立运行也可使用设置窗口。外部角色采用源码素材包流程，尚不支持运行时直接导入。

## 已知限制

- 当前支持 Windows 桌面。旧实时状态通道目前不可连接；可用本地状态仍有时效限制，宿主更新可能影响兼容性。
- 偶发公仔消失及长期运行后隐藏等待2–5秒仍待现场复现；自动检查通过不代表这两项已全部解决。
- 真实审批等待及解除尚未完整验收；不提供聊天直接发送、审批响应、独立完成提醒或回复草稿。
- 不同显示器、缩放比例和驱动下的最终窗口表现仍建议实际确认。

## 制作自己的公仔

附带[自定义公仔Skill](plugins/codex-pet/skills/create-codex-pet/SKILL.md)，支持换角色、替换动作，以及在源码中增加新的互动动作与触发入口。

- [下载独立Skill包](https://github.com/evanMai1021/codex-pet/releases/latest/download/create-codex-pet-skill.zip)，保留整个文件夹和参考文档。
- [制作与接入教程](docs/CUSTOM-PET.md)：图集格式、视频回退、动作触发和独立副本验证。
- [用豆包等AI生成视频](plugins/codex-pet/skills/create-codex-pet/references/ai-video.md)：需求单、抠像、透明WebM转换及验收。
- [可复制的视频提示词](plugins/codex-pet/skills/create-codex-pet/references/video-prompts.md)：共同约束、日常状态、互动、睡眠、趴边与新动作示例。

生成素材后仍需接入与验证；当前没有直接导入任意角色的按钮。外部AI的费用和素材上传由使用者自行决定，项目不会自动调用。
