## 旧版如何更新

不需要卸载，也不需要重新配置账户。先右键退出旧桌宠，再下载本页的 `inori-codex-pet-v0.1.13.zip`，完整解压到新目录。不要下载源码包当作便携版。

如需保留设置，将旧目录的 `resources/run-data/settings.json` 复制到新目录同一路径（没有目录则创建），再启动新 exe。不要搬运旧版程序文件或整个运行缓存。

若使用 Codex Pet 插件随启动，需将启动路径改为新 exe；详见 [更新步骤](USAGE.md)。本项目目前没有自动更新器，单独更新插件不会自动替换桌宠程序。
