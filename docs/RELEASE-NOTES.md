## 使用

在插件设置面板的“版本与更新”检查正式版本并点击更新；首次未安装程序时可安装桌宠。0.1.13 及以前的插件需要先手动升级一次才会显示入口。Windows 需要本机 Node.js 和可用的 Codex CLI，网络访问仅用于本项目公开发布源，不要求账户凭据。

插件更新后需要重新加载，当前聊天已加载的工具不会自动变更。版本提示和更新按钮位于本插件的面板，不冒充宿主插件列表的系统更新功能。下载或安装失败会显示错误并恢复已切换的程序路径，旧目录保留。
