# Codex Pet 0.1.12

本版将两套楪祈的连续动作、任务气泡与 Codex 内嵌设置整理为正式发布。保留0.1.11的趴边边界修复、服装选择和随 Codex 启停功能。

## 新增与改进

- 红白服和红黑战斗服共30张连续源图集、480格画面。每套15组：待机、工作、等待、招手、完成、出错、中断、打盹、睡眠、伸懒腰、比耶、未知状态和左/右/底部趴边。顶部由底部180度旋转派生，不另外计为新绘制帧。
- 睡眠分为一次入睡和循环呼吸；固定每组缩放与底部基线，保留原有动作触发时间。减少动态时固定画面；画面不变时避免重复重画和像素回读。
- 独立任务气泡显示任务名称、真实状态、公开进度阶段及明确的待操作提示。输入等待与审批分开，未知或失联不推断为待批准。
- 气泡标题可点击换句；可爱与撒娇合并，另有简洁语气，可保存一条56字符以内的短句。语句预览默认折叠，来自实际轮换文案。
- Codex 插件面板包含显示、随启动、服装、大小、减少动态、允许趴边、停靠位置、气泡开关、语气和自定义短句；修改立即生效并保存。移除“打开设置”按钮，保留“打开宠物”。独立运行时仍可从公仔右键打开本机设置。

## 下载与使用

普通用户下载 `inori-codex-pet-v0.1.12.zip`，解压并运行 `楪祈桌宠.exe`。开发者选择源码 ZIP 或克隆仓库。安装教程、使用教程和自制公仔 Skill 随源码提供。首次需要登录本机 Codex 才能取得对应状态，不额外要求填写 API Key。

从旧版升级：先从右键菜单退出旧公仔；在新目录解压，按需复制旧版 `resources/run-data/settings.json`；按安装教程将插件运行路径更新到新版 exe 并重新加载插件。不要覆盖正在运行的旧目录。

## 验证与已知范围

- 当前版本检查记录包括132项逻辑检查、151项图集检查、24项新增动作原生渲染检查，以及23项设置面板联动检查。设置联动使用实际 iframe、MCP处理器、本地设置接口和原生桌宠，Codex宿主连接部分为测试环境。
- Codex 内嵌面板在当前宿主中的最终显示尚未完成实机视觉确认，具体入口与展示由宿主扩展支持决定。新开聊天或重新加载插件后才会载入更新。
- 真实审批出现/解除全链路及部分并行中断场景未完整覆盖；模拟任务和窗口检查不代表这些场景已通过。桌面内部状态协议可能随 Codex 更新而变化。
- 当前动画使用 PNG 连续图集，包含透明 WebM 的可选播放入口，但未附带角色视频，不宣称已提供24fps视频或所有设备均无卡顿。
- 气泡不显示模型内部推理，不代替用户批准操作；现有用量条保留，不增加余额副本。
