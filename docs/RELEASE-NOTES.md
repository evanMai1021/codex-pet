## 安装与更新

插件设置面板 → 版本与更新 → 检查更新 / 安装桌宠 / 更新桌宠与插件。

Windows 需要本机 Node.js、可用的 Codex CLI 和网络。0.1.13 及以前的插件需先升级一次，才能显示新入口。更新插件后重新加载或新开聊天使用新版工具。此入口位于本插件面板。

如果已安装本轮整理前的中间包，请先退出桌宠，重新安装本页统一版插件并切换到本页便携程序；保留 `resources/run-data/settings.json`。中间包的版本编号曾较高，其旧更新器可能不会自动切换到统一版，需要这一次手动迁移；之后按正常更新流程使用。

## 验证与数据

本轮148项逻辑测试、14项Python测试及打包后资源63项窗口检查通过；实际ZIP隔离升级、设置迁移和同号插件刷新检查通过。此前退出修复验证：相同退出实现的正式包隔离回归连续三次约66–78毫秒隐藏，并以0正常结束；未关闭正在使用的 Codex 做完整宿主退出验收，宿主关闭插件连接的实际时机仍需正常使用确认。
