# Codex Pet 0.1.17 · 楪祈

- 插件面板提供“版本与更新”：当前程序、插件、最新正式版、更新说明和下载安装进度。程序与插件统一核对大小及 SHA256，迁移设置，保留旧目录。
- 保留已有插件来源；目标插件版本已安装时直接复用，避免 Windows 正在使用的缓存目录被重复替换。更新切换期间暂停设置和自动重连。
- 插件最后一个连接关闭时主动通知桌宠，保留主进程检测兜底；多个连接分别计数，只有开启随启动才因插件断连退出。
- 修复强制 app.exit 收尾导致 Electron 偶发残留：保存并隐藏后改走正常 quit。隔离真实 MCP/窗口/OS 进程连续三次验证，约 75–82 毫秒隐藏，均以 0 正常结束；不是关闭真实 Codex 得到的端到端结果。
- 安装切换检查旧程序 PID 是否真正结束，不能把控制文件删除当成进程退出；超时后仅处理身份匹配的旧桌宠进程。

## 使用

插件设置面板 → 版本与更新 → 检查更新 / 安装桌宠 / 更新桌宠与插件。

Windows 需要本机 Node.js、可用的 Codex CLI 和网络。0.1.13 及以前的插件需先升级一次，才能显示入口。插件更新后重新加载或新开聊天使用新版工具；入口属于本插件面板，不接管 Codex 插件列表的系统按钮。

只请求本项目 GitHub 公开版本和附件，不上传聊天或账户数据、不要求凭据。网络失败会显示错误并保留旧程序；安装失败恢复已切换的程序路径。实际 Codex 完全退出时，插件连接关闭的时机仍由宿主决定。
