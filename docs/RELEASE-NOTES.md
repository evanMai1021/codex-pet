# Codex Pet 0.1.16 · 楪祈

- 插件设置面板显示桌宠、插件、最新正式版和更新说明，提供检查更新、安装程序和下载进度；用户无需另开 GitHub 查找下载包。
- 程序和插件包均核对大小及 SHA256，再迁移设置并切换。保留已有插件来源，不直接改写宿主插件缓存。
- 修复已安装目标插件版本时仍重复安装的问题，避免 Windows 缓存目录被运行中的插件占用。首次从新版插件安装程序、只更新程序时均复用匹配插件。
- 更新切换期间暂停设置操作及自动重连；网络失败显示错误，保留旧程序；安装失败恢复已切换的程序路径。
- 退出采用插件连接主动通知加进程检测兜底。最后一个连接关闭且开启随启动时退出；多个连接不会因为其中一个结束而误关。隔离真实 MCP/窗口回归约 64 毫秒隐藏并正常退出，实际宿主结束插件连接的时机仍由 Codex 决定。

## 使用

在插件的楪祈桌宠设置面板 → 版本与更新 → 检查更新 / 安装桌宠 / 更新桌宠与插件。

Windows 需要本机 Node.js 和可用的 Codex CLI。0.1.13 及更早插件需要先升级一次，才能出现更新入口。插件更新后让 Codex 重新加载，当前聊天已加载的工具不会自动变更。此入口属于本插件面板，不是接管 Codex 插件列表的系统更新按钮。

仅请求本项目 GitHub 公开发布信息与附件，不上传聊天或账户信息，不要求登录凭据。下载结果必须通过完整性校验；临时网络失败可稍后再试，旧目录不会被自动清理。
