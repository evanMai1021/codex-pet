# v0.1.10

默认楪祈的 Windows 桌宠正式整理版，提供图形设置、允许趴边开关、自由靠边拖动修复和更清晰的额度文字。

附带默认素材、源码、可选 Codex 本地设置插件、使用教程及 create-codex-pet 制作 Skill。角色替换目前走源码素材包流程，尚无运行时一键导入。

下载：普通用户选择 inori-codex-pet-v0.1.10.zip，解压后双击 楪祈桌宠.exe；开发者选择源码包或仓库源码。首次需要登录本机 Codex 才能取得相应状态；不会额外要求填写 API Key。

检查：74 项源码逻辑测试、24 项原生窗口位置与详情检查、6 个实际 exe 渲染场景，以及素材/Skill/配置脚本检查已通过。真实审批等待及解除仍未完整覆盖；状态内部接口可能随 Codex 更新而变化。

截图中的额度与状态示例为模拟数据。代码 MIT，图片另见 ASSETS.md。本项目是第三方工具，非 OpenAI 官方产品。
