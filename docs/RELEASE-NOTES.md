# Codex Pet 0.1.14 · 楪祈

- 移除公仔头顶的任务状态圆点，任务状态仍可在气泡中查看。

- 插件面板新增“版本与更新”，显示程序、插件、最新正式版、更新说明和下载安装进度。
- 程序与插件统一校验大小和 SHA256，迁移设置并切换；保留已有插件来源，复用匹配的插件版本，避免 Windows 缓存目录占用冲突。
- 切换更新期间暂停设置和自动重连；安装失败恢复程序路径，旧目录保留。
- 插件连接关闭时核对 Codex 主进程是否真正退出；启动初始化或插件重连不会关闭公仔，进程状态未知时保留，继续独立检测正常退出。
- 保存并隐藏窗口后使用正常 Electron quit，修复强制结束导致的残留；升级时确认旧 PID 真正退出。

## 安装与更新

插件设置面板 → 版本与更新 → 检查更新 / 安装桌宠 / 更新桌宠与插件。

Windows 需要本机 Node.js、可用的 Codex CLI 和网络。0.1.13 及以前的插件需先升级一次，才能显示新入口。更新插件后重新加载或新开聊天使用新版工具。此入口位于本插件面板。

如果已安装本轮整理前的中间包，请先退出桌宠，重新安装本页统一版插件并切换到本页便携程序；保留 `resources/run-data/settings.json`。中间包的版本编号曾较高，其旧更新器可能不会自动切换到统一版，需要这一次手动迁移；之后按正常更新流程使用。

## 验证与数据

146 项逻辑测试与14项 Python 测试通过。相同退出实现的正式包隔离回归连续三次约66–78毫秒隐藏，并以0正常结束；未关闭正在使用的 Codex 做完整宿主退出验收，宿主关闭插件连接的实际时机仍需正常使用确认。
