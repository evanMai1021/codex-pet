# Codex Pet 0.1.14 · 楪祈

- 插件设置面板新增“版本与更新”：显示桌宠、插件、最新正式版和更新说明，可检查更新、安装程序并查看下载进度。
- 一键流程下载本仓库的便携包与插件包，核对 SHA256 和文件大小后解压，迁移设置、切换程序路径，再通过 Codex CLI 安装插件；不手工修改宿主插件缓存。
- 插件连接结束时主动通知桌宠；最后一个连接关闭且开启“随 Codex 启动”时退出，保留桌面主进程检测作为兜底。多个连接不会因为其中一个关闭而退出。
- 修正退出应答尚未完成时直接结束 Electron 导致进程退出卡住的问题。隔离真实窗口与 MCP 管道回归中，断连后约 77 毫秒隐藏并正常退出；实际 Codex 退出仍取决于宿主何时关闭插件连接，未把此测试当作真实宿主端到端验收。

## 使用更新入口

打开插件的楪祈桌宠设置面板，在“版本与更新”中点击“检查更新”；有正式新版时点击“更新桌宠与插件”。首次未安装桌宠时可点击“安装桌宠”。没有更新时不会自动下载，不需要自行打开 GitHub。

需要 Windows、本机 Node.js 和可用的 Codex CLI；更新不要求账户凭据。下载或安装失败会显示错误，旧版本保留；若程序路径已切换则恢复原路径。插件文件更新后需要让 Codex 重新加载，当前聊天不会凭空替换已加载的工具。

更新入口属于本插件自己的设置面板，不代表 Codex 插件列表提供相同的系统更新按钮。使用 0.1.13 及更早版本的用户，需要先升级一次插件到 0.1.14，之后才能看到此入口。
