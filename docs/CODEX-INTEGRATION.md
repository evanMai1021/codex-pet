# 在 Codex 内管理桌宠（0.1.12）

支持应用扩展的 Codex 宿主可从插件详情或“楪祈桌宠设置”面板调整全部10项设置。控件包括显示、随启动、服装、大小、减少动态、允许趴边、停靠位置、任务气泡、语气和自定义短句；语句预览默认折叠。修改立即生效并保存在本机。“打开宠物”只显示公仔；不再通过按钮跳转到独立设置窗口。

## 安装与刷新

先按 INSTALL.md 配置本地 exe 路径，再安装本地插件。更新插件和程序后，新开聊天或重新加载插件，使宿主载入新版资源及工具。当前宿主内的最终视觉显示尚未完成实机确认；具体入口由宿主扩展支持决定。独立运行时仍可从公仔右键进入本机设置。

面板通过 MCP 工具调用连接本机桌宠。未运行时可启动后台实例供设置连接，不自动显示公仔；要显示请开启显示开关或按“打开宠物”。接口共用原生设置校验和保存逻辑，浏览器不会取得本机控制端口或连接密钥。

## 随 Codex 启动与退出

随启动默认关闭。开启后在 Codex 加载插件并完成连接时启动，不添加 Windows 开机登录项或常驻助手。加载时机由宿主决定，可能晚于 Codex 窗口出现；每个插件服务进程只尝试自动启动一次，公仔另有单实例保护。

关闭随启动不会立即退出已运行公仔。公仔先检测到 Codex，再连续确认它完全退出后正常保存并退出；仅关闭窗口但仍在后台运行时保留公仔。检测失败视为未知，不因状态不明而退出；首次未检测到 Codex 的独立启动也保持可用。卸载前先退出桌宠。

## 验证边界

设置联动测试覆盖实际 iframe、MCP处理器、本机接口与原生桌宠，Codex宿主连接部分使用测试环境，不代替实际插件页面视觉验收。真实审批全链路尚未完整覆盖，模拟数据不计为真实审批通过。
