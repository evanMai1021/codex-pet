# 使用、更新与卸载

- 按住公仔拖动；单击互动，双击或点击底部额度条可展开、收起气泡。使用气泡底部分页切换任务、额度和今日 Token。
- 任务页可选择聊天，查看该聊天累计 Token；今日 Token 来自按日统计，二者口径不同。M 表示一百万，旁边或下方保留详细数字；无数据时显示未知。
- 公仔右键可调整公仔大小、气泡大小、自动任务气泡、趴边和停靠方向，恢复正常大小、回到屏幕中间、刷新额度、隐藏公仔和退出。隐藏与退出在菜单末尾同一组。
- 服装、减少动态、语气、自定义短句、随启动等完整设置位于 Codex 内嵌桌宠设置面板；独立运行时可通过 `楪祈桌宠.exe --settings` 打开设置。
- 不创建右下角托盘图标。隐藏后可从插件面板点击“打开宠物”，或再次启动 exe 恢复显示。
- 额度需要先核对显示的账户；未知额度不会显示成 100%。失败时可能显示上次快照或不可用，不是实时消费账单。
- “随 Codex 启动”默认关闭，开启后随插件加载启动，不添加开机项。检测到桌面 Codex 完全退出后桌宠结束；仅关闭窗口但后台还在运行时保留。状态读取失败不触发退出。

## 更新：不需要卸载

0.1.14 起，打开插件设置面板的“版本与更新”，检查并安装正式更新；首次安装也可从这里完成。更新下载需要网络，安装插件需要可用的 Codex CLI。当前聊天已加载的插件需重新加载后才能使用新版工具。

0.1.13 及更早的插件还没有此入口，首次升级按以下手动流程操作。

1. 右键公仔 → 退出，避免旧程序仍驻留或占用文件。
2. 从 GitHub Releases 下载最新 `inori-codex-pet-v版本号.zip`，完整解压到新目录。不要只复制 exe，也不要把源码 ZIP 当作便携程序。
3. 如需保留设置，先创建新目录中的 `resources/run-data`，再将旧版 `resources/run-data/settings.json` 复制进去。只迁移此文件；不要覆盖新程序或搬运整个旧缓存。旧设置里的已取消字段会被忽略。
4. 双击新目录的 `楪祈桌宠.exe`。确认右键菜单顶部显示新版本，再更新桌面快捷方式。
5. 如插件负责随启动，在新版源码包的根目录运行以下命令，将插件指向新 exe。配置脚本保留原配置备份；不读取账户凭据。

```powershell
python scripts/configure_plugin.py '新目录的完整路径\楪祈桌宠.exe'
```

插件来源本身也需更新到对应版本：源码 Git 用户在退出程序后执行 `git pull --ff-only`；ZIP 用户解压新版源码并在原来源位置更新插件文件。随后让 Codex 重新加载该插件。宿主插件来源管理入口可能随版本变化；此操作不要求修改 Codex 安装目录。只更新插件不能替换旧桌宠 exe，只换 exe 也不会更新旧的内嵌设置页面。

确认新版本显示、设置和随启动正常后，再自行处理旧文件夹。无需卸载再安装，也无需重复登录。源码启动的设置在仓库 `run-data/settings.json`，自定义 `INORI_DATA_DIR` 的用户继续使用原指定目录。

## 卸载与排查

先关闭“随 Codex 启动”，退出桌宠，再在宿主移除 Codex Pet 插件。程序和设置文件由用户自行决定是否保留；不要删除其他工具共享的配置目录。

未显示公仔时可从插件面板点击“打开宠物”；没有托盘入口。跨屏后位置异常可右键恢复正常大小或回到屏幕中间。源码缺少 Python 时设置 `INORI_PYTHON`。修改素材后运行素材检查脚本；JSON、manifest.js 及其引用文件必须一致。

自动更新保存旧版本，不批量清理文件。安装失败的诊断与下载进度保存在安装位置的 `pet-update-state.json`；不要分享包含个人路径或设置连接信息的运行目录。
