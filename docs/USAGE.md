# 使用、更新与卸载

- 按住公仔拖动；单击互动，双击展开或收起状态与额度详情。点击底部额度条也可展开。
- 右击 → 打开楪祈设置：选择红白服或红黑战斗服、开关显示、设置三档大小、允许趴边、选择方向、减少动态。服装切换即时生效，重启后保留；旧配置默认红白服。
- 关闭“允许趴边”会解除现有趴边；拖到边缘仍是站立姿势。开启后恢复拖动吸附。
- 右击 → 回到屏幕中间 / 解除停靠，可找回贴边的公仔。
- 额度需要先核对显示的官方账户；未知额度不会显示成 100%。失败时可能显示上次快照或不可用，不是实时消费账单。
- 程序只展示状态，不负责执行聊天任务，也不代替用户批准操作。
- 无需聊天打开：在 Codex 的插件列表进入 Codex Pet 详情，点击“打开桌宠设置”。支持应用入口的宿主还会提供“楪祈桌宠”控制页入口；不显示时可使用插件详情按钮或公仔右键菜单。
- “随 Codex 启动”默认关闭。在控制页、插件详情或设置中开启后，由 Codex 加载本插件时启动公仔；不开机自启，不运行常驻小助手。宿主延后加载插件时，公仔启动也会稍晚。
- 每个插件服务进程只自动发起一次启动。重新加载插件或重启 Codex 可能再次启动公仔；桌宠的单实例保护防止同一配置重复运行。关闭随启动开关不立即退出当前公仔。
- 公仔运行期间检测到 Codex 后，若连续确认桌面 Codex 已完全退出，会保存并退出；仅关闭窗口但仍在后台运行时保留公仔。状态读取失败不触发退出。此检查使用已有桥接进程，不增加开机项或独立常驻助手。

更新：先从右键菜单正常退出旧版，再将新便携包解压到新目录。便携版设置位于 `resources/run-data/settings.json`；如需保留设置，只复制此文件，不复制整个旧运行目录。再运行配置脚本，将插件启动路径更新到新 exe。当前窗口仍在运行旧版时，替换磁盘文件不会自动更新已加载的程序。

源码启动设置位于仓库 `run-data/settings.json`；可通过 `INORI_DATA_DIR` 设定自己的目录。

卸载：先关闭“随 Codex 启动”，再退出桌宠，在 Codex 插件目录卸载 Codex Pet；按需用 `codex plugin marketplace remove inori-pet-local` 移除本地来源。桌宠文件夹及设置由用户按完整路径自行决定是否删除。若 CodexPet/runtime.json 还被其他工具使用，不删除整个目录。本版本不注册开机启动项。

故障：未显示公仔先查看托盘；未连接状态先启动本机 Codex，确认账户与本地执行环境；源码提示找不到 Python 时重新设置 INORI_PYTHON；改图后空白先运行素材检查脚本，确认 JSON、图片和生成的 manifest.js 同步。
