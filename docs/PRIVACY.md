# 数据与本机状态

桌宠运行时读取当前用户 CODEX_HOME（未设置则为用户目录下 .codex）中的本地聊天数据库与近期事件记录，将聊天名称、阶段及状态用于本机展示。状态桥扫描近期事件以识别回合结束和中断，不将聊天正文作为展示内容或发送给维护者。

桌面状态客户端还连接本机 Codex 的内部状态通道；未来版本可能不兼容。额度查询使用本机已登录 Codex 提供的能力；程序不要求用户交出密码、令牌或 API Key，也不更改账号登录信息。

程序不提供向维护者上传数据的功能。截图中的聊天名称和账户信息可能敏感；反馈问题前请自行遮挡。请勿提交 run-data、runtime.json、本机 .codex 文件夹、日志或数据库。

`--no-bridge` 可用于关闭状态桥的界面检查；它显示状态源未连接，不代表没有任务。

分页气泡可读取本机聊天标题、标识、更新时间和累计 Token 元数据，用于选择聊天和展示用量；不读取聊天正文用于此选择器。今日 Token 与聊天累计 Token 分别统计，不作为实时结算账单。
