# 视频生成提示词模板

这些是制作需求，不是已经生成的素材。方括号内容由制作者填写，时长应按工具支持与真实动作选择。

## 每个动作共同使用

> 严格参考提供的角色图：[角色及服装描述]。保持同一角色、发型、发色、眼睛、服饰细节、头身比例与画风。固定镜头、正面全身、主体居中；全程完整保留头发、双手、手指、裙摆和脚，四周留安全空白。背景为均匀的[与角色不同色的纯色]，无纹理、无阴影背景、无场景、无地面渐变。只有角色动作，不运镜、不缩放、不切镜、不转场，不出现文字、字幕、边框、其他人物或物体。脸大小稳定，脚底锚点稳定，不漂移、不闪烁、不变脸、不增加或减少肢体。时长约[秒数]，无声音。动作要求：[从下表选一条并展开]。

“无声音”是需求，仍应在后处理移除音轨。“纯色背景”也不是透明，下载后需要实际抠像。

## 动作要求表

| ID | 建议画面 | 播放策略 |
| --- | --- | --- |
| idle | 轻微呼吸，偶尔眨眼，头身位置稳定 | 循环，首尾自然连接 |
| working | 轻微专注表情、小幅思考动作，保持原位 | 循环 |
| waiting | 温和注视、小幅歪头等待，不做完成庆祝 | 循环 |
| completed | 一次轻快的完成反馈，回到可停留的稳定姿势 | 单次，不无限庆祝 |
| error | 一次轻微困惑/受挫表情，稳定停留 | 单次 |
| interrupted | 收起当前动作，平静等待后续安排 | 单次 |
| unknown | 轻微疑惑观察，不做批准或完成手势 | 循环或稳定停留，按清单确定 |
| wave | 一只手清楚地挥动后放回原位，手指完整 | 单次 |
| peace | 一次比耶，保持手指数和动作轮廓 | 单次 |
| stretch | 一次小幅伸懒腰，手不越过画面边界 | 单次 |
| doze | 半闭眼、闭嘴，轻微困倦点头，不突然睡倒 | 循环 |
| sleepEnter | 从清醒过渡到闭眼睡眠，与睡眠循环衔接 | 单次 |
| sleep | 闭眼安静呼吸，稳定姿势，不重复入睡 | 循环 |
| dock-left | 按左边参考图，抓住左侧边缘，手脚保持构图 | 循环 |
| dock-right | 按右边参考图，抓住右侧边缘，手脚保持构图 | 循环 |
| dock-bottom | 按底边参考图，沿底边趴伏，固定脸大小与手部位置 | 循环；顶部由程序派生时不另生成 |

## 待机完整示例

> 使用参考图中的原创角色和同一套服装，固定镜头正面全身，角色大小和脚底位置始终一致。角色只轻轻呼吸，并自然眨眼一次，头发随呼吸轻微摆动，不走动、不转身。4秒内平稳完成一个可循环片段，首尾姿态、脸大小、亮度和背景完全一致。均匀纯色背景，背景色与角色和服装不同；全身及发丝、手指、脚均完整留在画面内，无文字、无其他物体、无镜头运动、无声音。

## 新动作点头示例

> 使用同一角色参考，固定镜头正面全身，原位轻轻点头一次表示回应，再回到起始姿态并稳定停留。只做一次，不循环点头，不改变服装和五官，不拉伸身体，不前后移动脚底，不切镜。头发、双手和脚完整留在画面内，纯色背景均匀，无文字、无其他物体、无声音。这个动作是普通互动，不表示真实任务已完成或审批已通过。

交给编码AI时另加：“动作ID为nod，按动作扩展参考补齐图集回退与真实触发入口；先在独立副本验证，不覆盖当前运行版。”

## 返工描述

只指出实际出现的问题，例如“第2秒右手多出手指”“循环接缝头部跳动”“待机脸比工作动作大”“下边趴伏遮住手指”。让模型保留已通过的部分，仅重做问题片段；不要反复改整套角色设计或用‘更可爱’替代可验收条件。
