---
name: setup
description: 安装楪祈桌宠或检查并更新程序和插件，保留现有设置。
---

先调用 pet_update_check，说明当前程序版本、插件版本和最新正式版本。
用户要求安装或更新时调用 pet_update_install；它下载本项目正式附件、校验完整性、迁移设置并通过宿主 CLI 安装插件。不要手工改写宿主插件缓存。
调用后用 pet_update_status 查看进度；显示 complete 才能声称完成。error 时说明实际错误，不盲目重试，不删除旧版。
仅询问有没有新版本时不下载安装。更新插件后需要宿主重新加载，不能把磁盘版本当成当前聊天已经加载的工具版本。
网络或 Codex CLI 不可用时保留原安装，说明缺失条件。状态、账户信息、设置连接令牌不得上传。
